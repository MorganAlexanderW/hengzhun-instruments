# 衡准仪表 HENGZHUN Instruments

> 精准测量，衡定未来 · Precision that defines the future

衡准仪表是一家面向未来的中国自动化仪表公司，专注**流量、压力、温度、物位、记录仪**五大系列过程测量仪表，以「国际品质 + 本土敏捷 + 数字化原生」为定位，打造高端国产替代品牌。

## 项目内容

### 公司官网（hengzhun-site）

纯静态网站，5 个页面，可直接部署到任意静态托管（GitHub Pages / 云服务器等）：

| 页面 | 说明 |
| --- | --- |
| `index.html` | 首页：品牌主张、五大系列、技术亮点、行业应用、数据背书 |
| `products.html` | 产品中心：五大系列 + 技术参数表 + 衡准云 |
| `industries.html` | 应用行业：石化、水务、能源、食药、冶金、公用工程 |
| `about.html` | 关于衡准：创始人故事、使命愿景、四阶段发展路线 |
| `service.html` | 服务支持：服务体系 + 联系信息 + 选型留资表单 |
| `assets/style.css` | 全站设计系统（深蓝 + 橙色工业美学） |

### 竞品分析与创业规划书

`衡准-竞品分析与创业规划书.html` — 11 章完整规划：

1. 执行摘要
2. 六大品牌深度对标（恩德斯豪斯 / 科隆 / 罗斯蒙特 / 艾默生 / 川仪 / 美仪）
3. 市场机会与战略空白
4. 创业蓝图（定位 / 使命 / 愿景 / 价值观）
5. 产品线规划与技术参数对标
6. 营销与销售体系
7. 网站规划
8. 组织与人才
9. 财务与融资节奏
10. 十年发展路线图
11. 风险与对策
